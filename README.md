# CS50W Network Project

A basic social media site built as part of Harvard's CS50's Web Programming with Python and JavaScript (CS50W) course.

This project was made using Django, written in the languages:

Python

HTML

CSS

Bootstrap

Javascript

# Features

Once Logged in, Users can create new posts

View all posts with more recent one appearing on the top

View their own and others profile pages, where they can see all the persons posts, their follower and following count, and be given the option to follow the account

A following page that only displays posts from people youve followed

The ability to like and unlike posts

The ability to edit your own posts

And a Pagination feature, where only ten posts are displayed at a time, with a next button appearing to go to the next page of posts
